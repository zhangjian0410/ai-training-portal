# 课程系列界面约定

本文件记录当前产品实现，供维护课程的人使用。正式站点由 Portal 组装，共用界面在这里维护；课程仓库负责自己的教材、图解、提示词、PPT/PDF 和练习项目。它不是要求学员学习的技术内容。

## 入口与学习路线

课程顶部固定次序：课程目录 → 课件 → 跟练 → 深入阅读 → 检查/自评 → 资料下载。当前栏目有底色与下划线，不能只靠文字颜色识别。标题回到本课封面，课程目录返回全站。

检查入口按真实目的命名：Skill 课是“自评 Skill”，Agent 课是“完成检查”，不把不同能力伪装成同一份评分。跟练可独立成页，也可定位到深入阅读的具体章节。后者进入跟练锚点时高亮“跟练”，回到深入阅读入口后高亮“深入阅读”。

PPT/PDF、参考包、原版海报等集中在资料菜单；原版海报继续支持在线查看与下载。菜单可键盘打开、Escape 关闭并把焦点还给菜单，点击外部也关闭。链接保持普通 HTML，即使脚本失败也可导航。

课件支持上一页、下一页、第一页、目录、左右键、Home 和 F 全屏；全屏将同一比例的课件和讲解放在一个窗口。手机显示可阅读的正文并保留翻页定位。最后一页的“下一页”改成“开始跟练”，退出全屏后出现后续路线。显示最后一页不等于用户已掌握知识，不自动计为完成或发证。

完成检查后可以回到跟练、进入课程反馈、下一门已发布课程，或建议下一门课。未来课程未发布时不提供虚假的开始链接。

## 视觉令牌

唯一正式来源 `src/ui-tokens.css`，构建时加载在课程历史样式之后。历史变量 navy/blue/muted 等通过别名接入共享值；课程内容图解的特殊布局由其原样式负责。

|角色|当前值|用途|
|---|---|---|
|正文与标题|#082f75|主要文字|
|主要操作|#1669db|链接、主按钮、焦点|
|辅助强调|#479df2|轻量图形强调|
|次要文字|#5274ac|说明与标签|
|分隔线|#bcddfb|边框和分区|
|浅色面板|#eef7ff|提示词、次要按钮|
|页面/内容底色|#f3f8ff / #fff|页面与阅读内容|
|正文字体|PingFang SC / Microsoft YaHei / Arial|本地系统字体，不增加字体请求|
|标题字体|PingFang SC / Heiti TC / Microsoft YaHei|沿已有课件风格|
|代码字体|SFMono-Regular / Consolas / monospace|提示词中的代码和配置|
|字号|14 / 16 / 20 px|辅助 / 正文 / 引导；标题按视口适配|
|间距|4 / 8 / 12 / 16 / 24 / 32 / 48 px|统一节奏|

`src/course-shell.css` 消费这些令牌，控制导航、阅读、资料菜单、按钮、留言和后续路线。课件图像保持16:9；PPT/PDF已经使用同一蓝白色系，不因网页导航变化重绘导出。减少动画偏好生效；可见键盘焦点不能删除。

## 单一实现与新增课程

- `src/courses.json`：课程来源与真实入口，以及 `ui.shortTitle`、`ui.reviewLabel`、`ui.downloads`。下载项 `download:false` 用于在线查看。
- `scripts/course-shell.mjs`：统一导航、资料菜单、后续路线及注入；缺少可适配的标题结构时构建失败。
- `src/course-player.js`：正式站点两门课共用的播放、预加载、全屏和复制逻辑。来自已验证的现有播放实现，新增末页引导。
- `src/course-shell.js`：同页跟练定位和资料菜单交互。
- `scripts/build.mjs`：把上述资源与课程组装，`build-info.json` 同时记录课程 commit 和 `uiVersion`。共享资源 URL 带内容指纹，避免更新后误用旧缓存。

新增课程需提供与现有课程一致的标题、课件与讲解 DOM 结构；不同结构先加显式适配，不能静默套用。现有课程仓库中的旧播放副本仍服务独立预览，正式 Portal 统一替换其 app.js 引用。只改课程旧副本不会改变正式共享播放逻辑；需要同步到 Portal 并验证两门课。课程语义和PPT内容不在 Portal 复制维护。

新课程登记后检查主导航、在线资源与下载、最后一页、阅读和检查页、反馈范围，以及桌面/手机/全屏。登记课程序列决定“下一门课”的目标，所有链接都由真实目录生成。

## 验证与发布

`npm run build && npm run check && npm test` 覆盖组装、链接、共享界面结构及现有互动 API。`tests/course-shell-browser.mjs` 覆盖两门课的25页全屏、菜单/复制/当前栏目/末页路线与手机布局；它屏蔽互动脚本，不向生产提交测试留言或访问事件。

浏览器测试要求 Playwright；已安装时直接运行，或用 `PLAYWRIGHT_MODULE` 指定现有模块入口。设置 `COURSE_TEST_URL`（默认本机8768）及 `COURSE_TEST_EVIDENCE_DIR` 输出截图/回执。不自动安装或更改全局环境。

发布前做独立复核和验收；发布后核对 build-info、共享资源指纹与浏览器实际行为。回退共享界面只需回退 Portal 版本，不回滚留言数据库，也不更改课程内容提交。
